四、归因（逐项 + 5-Why 根因）

  • 系统性 risk-off 日：创业板 -2.61% / 科创 -2.10% / 深证 -2.03%，上证 -0.43% 靠银行独撑。周末"政策利好牛市"叙事（新质生产力顶层文件、医药十五五、稳市组合拳、人形机器人出货暴增）被风险偏好压制，未转化为周一买盘。
  • 看多全失准共因：把"顶层文件 / 规划 / 出货数据"等中长期逻辑直接映射为"周一方向"，缺当日可交易催化 + 缺大盘 regime gate。与 8/31、9/7、9/14、9/28 同源（第 5 次重复）。
  • 看空"命中"是假阳性：半导体整体 / 光伏 / 数据中心电源 下跌因全市场 β，非源简报精准判断（当日主力净流出、主跌出货）。普跌日"看空"天然高命中，应剔除 β 成分或计中性，否则虚高命中率。
  • 银行"命中"需警惕价涨钱出：20 日主力净流出超 94 亿，属避险抱团+护盘，非增量进攻资金；若解读为"资金看好"将误导。
  • 真正 α = 银行（政策+防御双击，唯一逆市板块），但资金面揭示其涨不可简单解读为增量看好。
  • V4 框架诚实注记：源简报的 V4 预判（人形机器人 P2 确认、创新药/CXO P2 确认、半导体存储 P2 确认等）在 10/12 risk-off 下，D0 单日 ≥5% 触发条件全部未满足（这些板块均下跌，无任何一只单日涨幅 ≥5% 触发），V4 状态机根本不会进入 P1，更不会 P2 确认。故源简报"P2 确认预判"属休市期外推、未经 D0 触发验证的过度定级；按 V4 铁律应记为 WAIT / 未触发。

5-Why 根因链

  1. Why1 命中率仅 30.8%？→ 看多 9/13 全失准。
  2. Why2 看多全失准？→ risk-off 日 β 淹没 + 政策逻辑未转化为周一买盘。
  3. Why3 为何无 regime gate？→ 源简报在休市期撰写，缺当日大盘/风险偏好判定。
  4. Why4 为何看空"命中"也计分？→ 评分未剔除 β（普跌日看空天然高命中）。
  5. Why5 根因 → 周末新闻→周一方向映射缺少【大盘 regime gate】+【看空命中 β 剔除】+【V4 状态机 D0 触发约束】+【资金对抗（价涨钱出）】四道防线。

五、后续修正建议

  1. 加大盘 regime gate：risk-off 日（创业板/科创跌幅 > 大盘 1.5pct 且成长领跌）所有"看多"自动降级为"观察"，不强行给方向。
  2. 看空命中须剔除 β 成分：全市场普跌（上涨家数 < 30%）时，看空命中不计分或计中性，避免虚高。
  3. 政策/规划类利好标注"T+交易日验证窗口"：不默认周一兑现；除非有明确当日催化（业绩/订单/批复），否则只作"中期偏好"而非"周一方向"。
  4. 资金对抗必做：凡"当日涨"须查 20 日主力净流入，价涨钱出一律不得判资金看好（银行即典型）。
  5. V4 定级必须 D0 触发约束：单日 ≥5% 触发后才允许进入 P1；休市期只做"候选"不写"确认"，周一开盘后按状态机复核。
