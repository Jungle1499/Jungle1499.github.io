三阶段理论框架（第一性原理 = 人性的扩张与收缩）：
板块周期 = 犹豫期 → 共识期 → 加速期；
P1（启动）：逻辑龙头先涨；
P2（二线）：后排补涨、涨速反超龙头 = 人性扩张；
P3（高潮）：龙头涨速反超、群体狂热；
配对原则 = 市值可匹配 + 业务类似 + 涨幅最大的两只（如光模块 Pair = 中际旭创 / 新易盛）；
阶段确认 = 板块进全市场涨幅前三 = P1 预警，Pair 中一方连续 2 天跑赢另一方逐级确认 P1 / P2 / P3；
买卖 = P1 试错买入、P2 加仓补涨、退潮周期 P2 确认即卖。

与金融 Skills / 已连接数据源的对应关系

框架每个判定环节都能用已装的技能栈直接落地：框架全部输入信号，现有四库（westock / mx-ds / tdx / wind）+ 6 个金融 skill 都能取到，不存在"数据够不着"的环节。唯一缺口是"相对强弱自动计算 + 信号判定"，需写个小脚本（读日K→算 2 日跑赢→输出 P1/P2/P3 状态机）。

优点（5 条）

  1. 有第一性原理根基："人性的扩张与收缩"对应行为金融的群体情绪钟摆，犹豫→共识→加速与板块生命周期实证规律一致，不是玄学。
  2. 规则可量化、可回测：所有判定（涨幅前三、连 2 天跑赢）都能转成明确条件，具备被历史数据验证的前提。
  3. 相对强弱配对设计精巧：用同板块 Pair 内的强弱切换识别阶段，天然剔除大盘系统性噪音，比看绝对涨幅更抗干扰。
  4. 买卖纪律闭环：P1 试错 → P2 加仓 → P3 撤退，符合"截断亏损、让利润奔跑"的趋势跟随原则。
  5. 与现有技能栈 100% 可对接，且 8/12 报告已用它实战判定 CPO 主线 P3 确认清仓。

硬伤（6 条）

  1. 确认滞后，右侧交易：全部基于日线收盘 + 连 2 天确认，P2/P3 信号发出时涨幅大多已兑现大半；P3 确认 ≈ 情绪顶部附近——"确认即顶"是右侧框架宿命，容易吃鱼尾。
  2. "逻辑龙头"标定主观：Pair 里谁是龙头、谁是补涨，需先验知识，框架本身没给自动判定方法，执行依赖人工或资讯辅助。
  3. "2 天"阈值无依据：是经验值，未回测校准；强板块和弱板块用同一阈值，必然误判。
  4. 情绪周期循环依赖：买卖策略里"上涨周期拿到 P3 / 退潮周期 P2 即卖"，但"上涨/退潮"本身怎么判定，框架没定义。
  5. 风险控制缺失：没有止损、仓位上限、最大回撤、单票集中度的定义。
  6. 事件干扰无防御：停牌、减持公告、监管问询会瞬间破坏 Pair 相对强弱，2 日规则直接失效。

改进建议（都能用现有技能栈落地）

  1. 回测校准阈值：用 tdx/wind 历史日K 跑 P1/P2/P3 状态机，统计各阶段胜率/盈亏比，把"2 天"校准成该板块最佳参数。
  2. 补齐情绪面板：涨停数、连板高度、炸板率、涨跌家数做退潮期判据，解决循环依赖。
  3. 风控参数化：P1 试错 ≤10% 仓位、单票止损 -8% 或跌破 Pair 另一只收盘价、P2 加仓仅在 P1 浮盈后。
  4. 盘中提前确认：用 tdx 30 分钟 K 线把 2 天滞后压缩到 1 天半，P2/P3 预警提前一天。
  5. 龙头自动标定：用"板块内 5 日涨幅第一 + 主力净流入第一"自动识别逻辑龙头，去掉主观。
  6. 模拟盘验证：用 westock 模拟交易按规则下单，积累实盘对照样本后再上真金白银。
综合结论：这是一个逻辑自洽、纪律明确、但确认滞后且无风控的右侧趋势跟随框架。作为复盘归因工具（事后解释板块为什么涨、处于哪个阶段）它非常合格——8/12 用它判 CPO P3 确认清仓就是成功案例；作为实时交易系统还差三件套：回测校准阈值 + 情绪面板 + 风控参数，而这三件恰好都能用现有四库数据源实现。
