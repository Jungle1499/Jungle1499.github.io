• 10/08（节后首日）：AI应用 / 传媒 / 电池 / 种植 多线开花

4. 主线阶段结论

军工整体处于 P1→P2 过渡：地面兵装（P2确认）、军工电子（P1确认）走在前；航空装备 / 航海装备 / 航空发动机 / 上游电子材料均 P2预警（补涨首日启动）；退潮线（传媒/AI安全）派发。主升浪尚未进入 P3 高潮，行情定性为“超跌反弹 + 事件驱动”，机构普遍定位“反弹非反转”，不宜上头。

5. 风险提示

① 估值透支：军工多标的高PE（洪都航空509 / 航发科技226 / 内蒙一机105），情绪交易占比高，地缘一旦降温易快速回撤。
② 缩量 / 杠杆撤退：融资余额连续2日下降；军工行业20日主力净流入仍大幅为负（如航空装备20d -50.96亿），今日放量若为短线博弈资金，持续性存疑。
③ 海外映射 / 地缘不确定性：印巴局势为情绪驱动，冲突缓和即催化消失；印度2026/27国防预算+15.2%至856亿美元，区域军备竞赛双刃剑。

⑤ 退潮线派发扩散：传媒/AI安全（芒果/绿盟）5日强但当日转绿，警惕高位派发向其它高位方向扩散。
