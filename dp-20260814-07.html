三阶段理论框架 （框架 v2.0 · 一性原理 = 人性的扩张与收缩 · 规则 三-①~三-⑥）

板块行情的完整周期分为三个阶段：犹豫期 → 共识期 → 加速期。

P1（启动）：逻辑龙头先涨；P2（二线）：后排补涨，涨速反超龙头 = 人性扩张；P3（高潮）：龙头涨速反超，群体狂热。

配对原则（三-②）：锁定"市值相差不超过 5 倍 + 业务类似（多维度：公司介绍 / 板块概念 / 三级行业分类 / 概念标签 交叉确认确属同类赛道） + 涨幅最大的两只"的 Pair；市值差 > 5 倍 或 业务不属同类赛道均不构成有效 Pair，须换标的配对，脱离 Pair 不判阶段。示例：光模块主升浪 Pair = 中际旭创 / 新易盛，PCB 主升浪 Pair = 胜宏股份 / 沪电股份。

起涨/阶段确认（三-①）：板块进入全市场涨幅前三 = P1 预警；Pair 内一方连续 2 天跑赢另一方逐级确认 P1 / P2 / P3（龙头连续 2 天跑赢补涨 = P1 确认；补涨连续 2 天跑赢龙头 = P2 确认；龙头再连续 2 天跑赢补涨 = P3 确认）。P1 预警后后排仅跑赢 1 天 = P2 预警，需重新计数。

逻辑龙头自动标定（三-⑤）：板块内"5 日涨幅第一 + 主力净流入第一"自动识别逻辑龙头，去除主观；若两条件分属不同标的（小市值情绪股 5 日第一、大市值总龙头主力净流入第一），以大市值产业总龙头为逻辑龙头锚，小市值标的仅作情绪温度计。

买卖（三-③）：P1 试错买入（≤10% 仓）；P2 加仓补涨（仅 P1 浮盈后）；退潮周期 P2 确认即卖。三-④ 确认滞后：P3 确认≈情绪顶部附近，右侧框架易吃鱼尾，须配合风控与盘中 30 分钟 K 提前确认；本判定作为 20:30 回测源（回测维度 ⑤），并供 08:00 盘前方向表 stage-aware（三-⑥）引用。
