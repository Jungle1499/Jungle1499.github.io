三阶段理论框架（P1 启动 / P2 二线扩散 / P3 高潮·退潮）

第一性原理：人性的扩张与收缩
资金先在最确定的逻辑龙头上"试错"（P1），确认赚钱效应后向同板块二线"扩散"（P2），最后在无差别补涨与群体狂热中见顶（P3 / 退潮）。阶段不是靠价格猜的，是靠Pair 相对强弱的连 2 天确认数出来的。
P1 启动
逻辑龙头率先涨停 / 板块广度 <70%
纪律：试错买（≤3%）
P2 二线扩散
二线补涨、广度 ≥80%、梯队完整
纪律：加仓（≤10%）
P3 高潮 / 退潮
补涨票反超龙头（群体狂热）、高度炸板
纪律：退潮 P2 即卖
配对原则（三-②）：市值匹配（比值 <5x）+ 业务类似 + 板块内涨幅最大两只。确认滞后（三-④）：阶段升级须"连 2 天跑赢"方可确认，单日反超不升级。权重锚（三-⑧）：市值远超板块其余成分（>5x）的权重龙头单列，另取二线配对。买卖（三-③）：P1 试错 / P2 加仓 / 退潮 P2 即卖。门控（三-⑥）：全局退潮期（涨跌比 <0.4 或 炸板率 >30% 或 首板无溢价）方向表整体降权。
