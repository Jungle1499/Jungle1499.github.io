0. 美国 FCC + 商务部对华科技限制升级（重大·持续发酵）【通信 / 光模块 / 半导体 / 机器人 / 储能逆变器 · 利空出口链 · 利好国产替代 · 高】⚠️ 8/23 补录 + 深化（含 ITI 行业反弹、储能维度、品类扩张框架）

A. 监管动作（一手源 / 案卷 21-232、DA 26-786、FCC-26-50） - FCC 26-50「零部件漏洞封堵」规则落地（8/11 批准）：限制含华为/中兴等 Covered List 企业"逻辑硬件"组件的第三方设备获取新 FCC 认证，封堵贴牌/组装绕路（ET News 8/12）。 - FCC 起草禁止进口中国新型光模块（8/4 路透）：拟禁中国新型号光收发模块，仍可能修改/搁置；BankInfoSecurity（8/17）指出"无草案文本、未开程序、未定范围"，TrendForce 判"过早视作全面禁令"（中新网 8/4 / BankInfoSecurity 8/17）。 - FCC 7/28 DA 26-786 将「外国生产电力逆变器（含储能 PCS）」列入 Covered List：仅前瞻、按型号祖父条款、65% 美国成分门槛（2029→75%）；储能系统"可进口性 = 其 PCS 是否持 FCC 授权"（pv-magazine-usa 7/28 / The Energy Storage Wire 7/30）。 - 中国商务部反制（8/5）：无人机出口管制等四项措施（证券时报 8/13）。

B. 行业反弹（关键增量·此前漏报）🔗 用户重点提示 据美国通讯权威媒体 Communications Daily（8/18，案卷 21-232） 报道，美国科技行业协会 ITI（Information Technology Industry Council，会员含 Amazon/Google/Microsoft/Nvidia/AMD/OpenAI/Broadcom 等） 正式敦促 FCC 不要将外国制造光收发器列入 Covered List，并呼吁对"已新增的机器人和光伏逆变器"给更清晰细则。ITI 三层立场：① 原则——Covered List 应"精准、风险为本"，聚焦与外国对手明确关联的实体/产品；② 品类——明确反对把光收发器纳入，尤其反对"所有外国生产光模块"一刀切；③ 兜底——若 FCC 仍推进，应收窄到已列名实体 + 与业界沟通清晰定义。这是边际缓和信号，但非终局（FCC 仍可窄做）。ITI 信件落款 8/13、会议记录 docket 21-232。（Communications Daily 概况/可站内搜 optical transceivers / BankInfoSecurity 8/17 光模块草案）

C. 为什么同时牵动储能（用户重点） 逆变器禁令直接打在"储能可进口性"上——电池系统能否进美国 = 其 PCS 是否持 FCC 授权；近月 TD Cowen 判"非事件"（存量型号祖父），但刷新周期（约 1 年）后新品种需重认证 → 中长期压缩合格供应商、推高价格与交期。阳光电源（全球市占超 25%、与 Chint 合计占美 Utility 约 60%）、德业/锦浪/固德威/科士达/上能/艾罗/首航等对美敞口标的，阳光电源较 6/30 已跌约 1/3，部分 price-in。反身性：美国本土仅满足 7% 逆变器需求，禁令推高光储项目成本、拖累 AI 数据中心供电（AI Action Plan 依赖光储），这正是 ITI（会员为 AI 巨头）出面反对的底层动机；若 FCC 采纳"窄、实体级"思路，储能逆变器恐惧缓和，反之则持续悬剑。

D. A股 影响拆解 + 品类扩张框架 - 利空：出口导向型光模块/通信/机器人/逆变器对美敞口（情绪 + 认证壁垒）。 - 利好：国产替代 + 内需算力/半导体设备/自主可控；光芯片（源杰科技/仕佳光子）、国产逆变器替代。 - 品类扩张风险（框架要点）：同一"外国生产 + 联网 + 国安"逻辑已跳品类——路由器(3月) → 消费级路由器 → 机器人+逆变器(7/28) → 光模块(草案)。须持续盯下一品类。 - 机构普遍判"草案/拟议落地难、实质影响有限"（中国光模块产能占全球约七成、美国短期无法替代、头部厂商泰国建厂对冲），但"拟议→落地"节奏与豁免口径是中期最大变量，市场交易的是情绪，长期比拼良率/交付。 - 注意：初始事件在窗口前（8/4–8/11），但属影响周一通信/光模块/机器人/储能情绪与定价的持续重大主题，本应纳入"周一潜在影响"。

三、三阶段框架判定【框架应用 三-①】

判定逻辑：P1 启动 = 政策 / 事件催化刚落地、资金初动；P2 二线 = 景气 + 事件扩散中、参与者增多；P3 高潮 = 趋势性强势后期 / 兑现期，追高风险上升。

  • 通信 / 算力 / 6G → P1 启动：政策 8/21 刚定调，周五已有涨停潮反映资金抢跑，属"刚启动 + 初动"，但需防利好兑现。
  • 半导体存储 / 设备材料 → P2 二线：长存受理 + 税收优惠 + 景气反转 + 中报高增，事件密集扩散，但未到 P3（巨无霸 IPO 分流 + 周期拐点隐忧）。
  • 贵金属 / 黄金 → P3 高潮：突破关键整数关口、周线五连涨，主升行情，注意高位追高。
  • 有色 / 资源 → P2 二线：跟涨贵金属 + 美元走弱 + 供需 + 业绩，资金抱团扩散中段。
  • 机器人 / 具身智能 → P2 二线：大会密集催化 + 政策（质量强链二期）+ 产业化加速（成本下探、批量采购），进入"全面铺开"深水区，未到全面高潮。
  • AI 算力硬件 → P2 二线：业绩高景气兑现 + 事件（涨价 / CPO / 大厂囤卡），但内部分化（CPO 冲击传统光模块）。
