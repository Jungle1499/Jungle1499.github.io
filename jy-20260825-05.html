① 什么是华为「韬(τ)定律」

由华为 何庭波 在 ISCAS 2026（2026-05-25） 主旨演讲提出，2026 年秋季随新一代麒麟（逻辑折叠技术）落地进入催化窗口。核心思想：以「时间(τ)缩微」替代「几何缩微（摩尔定律）」——靠 逻辑折叠 LogicFolding + 2.5D/3D 堆叠 + Chiplet + 混合键合 在成熟制程（7/14nm）上实现接近先进工艺的性能，弱化对 EUV 的依赖。预计到 2031 年高端芯片晶体管密度达 1.4nm 等效水平。

  • 受益逻辑：成熟制程价值重估 + 先进封装从"配套"变"核心增值环节" + 国产 3D EDA 增量 + 堆叠设备/高端材料/散热需求爆发。
  • 七大受益方向（申万宏源梳理）：晶圆代工 / 先进封测 / 半导体设备 / 核心材料与散热 / EDA·IP / 大芯片设计 / 算网。
  • 催化节点：2026 秋季麒麟落地、V2 论文公开工艺参数、四代麒麟/昇腾路线图、产业链订单兑现。
