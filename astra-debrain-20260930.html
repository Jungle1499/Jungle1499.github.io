Astra「去大脑化」→ 受益环节 → 筛选标记 → 标的 v3.0 定级

口径声明：本报告不采信「OpenAI 因该模型 ARR 到 700 亿」这一说法（ARR 由企业/订阅/Codex/广告驱动，与该模型无因果）；「李飞飞世界模型被 OpenAI 收购」亦为误传（实为 AMD 收购 World Labs）。以下只讨论 GPT-6 Astra + HomeBody 这条技术路线。

一、去大脑化：Astra 到底删掉了什么

1
旧架构：VLM（看）→ VLA（端到端动作策略，需海量示教/训练） → 控制器 → 本体。各机器人公司自研的 VLA 就是它的「大脑」，也是护城河。
2
HomeBody（Stanford + Caltech，9/26–27 开源）做的事：把 GPT-6 Astra 直接接进宇树 G1，删掉了那层训练好的 VLA 控制层。Astra 只接管「规划/决策」，动作执行下沉给可替换的标准化技能库 + 本地控制器。
3
所以「去大脑化」的真实含义：不是机器人不要大脑，而是大脑从「每家自研、端到端训练的专属 VLA」变成「可热插拔的通用认知模型」。Astra 是通用商品化大脑，插上就能用。
4
价值链后果（最关键的一步）：护城河从「算法/大脑」下移到「标准接口 + 可被调用的合格零部件」。谁家的 VLA 写得更好，不再是胜负手；谁能被大脑厂商直接找到、直接调用、稳定供货，才是。
5
→ 去主机厂化：大脑厂商（OpenAI 及同类）若要落地本体，倾向直采合格零部件，而非经由整机厂。这正是你 sharpened 标准的由来：做对产品 + 已过审厂 + 有北美/可服务美国海外产能。
必须打折的地方（别把 PoC 当量产）：HomeBody 目前是实验室验证（宇树 G1 + 仿真数字孪生），证明的是「换环境不用重训控制层」这条路走得通，不等于已量产、不等于 OpenAI 已下单。A 股这些标的真实的基本面催化仍然主要是特斯拉 Optimus 供应链订单，Astra 叙事提供的是估值弹性与想象空间，不是当期业绩。

二、真正利好的环节：是不是就是「海外产能 + 已送样审厂」

结论：是，而且这两个条件恰好是硬约束，不是锦上添花。
先看「大脑 + 动作库」这套机理真正让什么量变大：
  • 标准化关节/执行器总成——动作库要可复用，前提是关节性能一致、可替换，通用执行器先放量。
  • 谐波减速器 / 丝杠——传动件从「定制」转向「标准品」，通用型号放量最直接。
  • 力 / 触觉传感器——删掉端到端训练后，柔顺控制与力反馈要靠硬件感知补回来，六维力是新增量。
  • 轻量化精密结构件——本体通用化后，结构件走向标准平台件。
  • 空心杯等微特电机——灵巧手自由度提升的直接受益件。
再看为什么「海外产能」和「送样审厂」是准入门槛而非加分项：
  • 海外产能：大脑厂商/整机客户在北美，关税 + 交期会把纯国内产能直接挡在门外。美国本土 > 墨西哥近岸（72h 达德州）> 泰国等可服务北美的产能，这是「能被直接调用」的物理前提。
  • 送样审厂：NDA → 送样 → 审厂 → 小批 → 批量，是零部件进入任何大脑厂商/整机厂供应链的必经闸门。没过审厂，产品再对也只是「潜在」。
所以筛选不变量就是这两条 + 产品对位：产品必须在上面那张受益清单里，且已过闸门，且产能落在北美可达范围内。「是不是特斯拉供应商」不是必要条件——特斯拉本身也是主机厂，去主机厂化恰恰意味着可能被绕过；它只是「质量已被验证」的强信号。

五、怎么读这张表（操作纪律 · 三-③）

  • P1 确认 = 试错买入龙头（不是补涨）；P2 确认 = 调仓加补涨。
  • P3 确认 = 持有（v3.0 已废「确认即清仓」），直到龙头真跌或双双跌才 W 结束。
  • 中断只看龙头：龙头单日跌 ≥6% 才触发，补涨跌不算；次日反包可恢复。

六、未核实 / 风险

  • HomeBody 为实验室开源验证，未量产；OpenAI 是否直采零部件无任何公开证据，属期权而非基准情形。
  • 斯菱智驱的 T 链一供为机构口径，公司 2026 年 6 月称「未与特斯拉合作」，待确认。
  • 4 只 T3 配对标的（旭升/江苏雷利/贝斯特/东华测试）本轮未做送样/海外产能逐项核验。
  • v3.0 定级基于 westock 前复权日线回测，未使用板块资金流交叉验证；Pair 配对按业务相近选取，与「市值匹配」为近似处理。
  • 本报告为研究记录，不构成投资建议。
