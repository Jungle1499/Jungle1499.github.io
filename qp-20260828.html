三阶段理论框架（预判底层逻辑）

第一性原理 · 人性的扩张与收缩
板块/个股炒作本质 = 群体情绪从「怀疑(扩张)」→「一致(高潮)」→「恐慌(收缩)」的循环；资金在 P1 试探、P2 加仓、P3 派发。判断主线必须先定阶段，再给方向。
阶段定义（三-①~三-⑤）
· P1 启动：板块首次进全市场涨幅前三 / Pair 内一方启动，疑信参半。
· P2 共识：Pair 内两只连续 2 天跑赢且扩散到二线，资金连续流入确认（三-③）。
· P3 加速：全市场公认主线、鸡犬升天、放量加速（三-⑤ 降权信号）。
· 退潮：P2 确认后高位放量滞涨 / 龙头断板，立即降仓（三-⑥/三-⑦）。
配对原则（三-②）
市值匹配 + 业务类似 + 涨幅最大两只：
· 农资链 Pair = 万向德农(逻辑龙头) / 敦煌种业(补涨)
· 化工 Pair = 昊华科技(原龙头·今机构-5.19亿出货) / 潞化科技(补涨)
· 黄金 Pair = 湖南黄金(权重) / 莱绅通灵(连板补涨)
· AI硬件 Pair = 中际旭创 / 新易盛（今日双双主力净流出=诱多出货 ⑳）
买卖纪律（三-⑥ stage-aware）：P1 试错买（小仓）/ P2 加仓（主仓）/ P3 减仓（不追）/ 退潮 P2 即卖。任何 P3 或退潮阶段的方向一律不得给「多」，只能中性或减仓；未做 P1/P2/P3/退潮判定不得给方向（三-⑥）。相对强弱按 Pair 连2天跑赢逐级确认（三-③/三-④）。
