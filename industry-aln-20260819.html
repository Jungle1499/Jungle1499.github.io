① 主题逻辑：为什么是氮化铝

  • 痛点：AI 光模块（1.6T/3.2T）、CPO、车规 SiC 功率器件、5G 射频（BAW）散热与绝缘需求爆发——传统氧化铝基板热导率（~25W/m·K）不够，需切换 氮化铝（AlN，热导率 170~230W/m·K）。
  • 三大驱动（多信源交叉）：
    • ① 1.6T 光模块：单台氮化铝基板用量是 800G 的 1.5~2 倍；DPC 薄膜氮化铝基板全球仅京瓷+中瓷能量产，中瓷 1.6T 订单锁定至 2027 年底；
    • ② CPO / AI 算力散热：英伟达 CPO 封装 AlN 基座（中瓷为国内唯一国产供应商）、AI 服务器大功率散热基板；
    • ③ 800V 车载 SiC + 军工：AMB/DBC 氮化铝基板适配新能源车 800V 平台；HTCC 氮化铝管壳用于军工微波/卫星射频，算力+军工双逻辑。
  • 供给格局：高端粉体/基板长期被日本德山、京瓷垄断；国产粉体突破（国瓷对标德山、旭光 500→1500 吨扩产、金博在建），国产替代率低 = 空间大；粉体产能 2026-2027 集中释放。
  • 催化时间线：8/13-14 板块突现强度（中瓷/旭光双板 + 金博 +13.6%）——与英伟达 800VDC 白皮书（8/13 北京）同期的"AI 算力电源/散热"主线共振；8/17 扩散（博敏/有研/旭光/中瓷集体涨停）；8/18 分化（二线接力、龙头歇脚）。
  • 三阶段判定（三-①，已用真实日K校准）：P1 启动（确认） → P2 过渡中。龙头中瓷电子 8/11 起领涨、8/14 首板、8/17 连板；8/18 二线旭光三连板/博敏二连板反超 → P2 扩散信号已现，严格 P2 确认（连续 2 日跑赢龙头）待 8/19 验证。

行情阶段：P1 启动（确认）→ P2 过渡中

  • P1 已确认：8/14 催化日龙头中瓷+旭光双板、8/17 扩散多股涨停，逻辑龙头先涨完成；

匹配结论：产业成长期早期 + 行情 P1→P2 = 题材由预期转向业绩验证的第一波主升初期，通常是最肥的一段；操作纪律按三-③：P1 试错龙头（中瓷）、P2 加仓最强二线（旭光/博敏），一旦二线连板断档且龙头不接力 → 降级观望。
