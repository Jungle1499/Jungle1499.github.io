八、核心驱动（四层拆解）
P0AI应用 / AI视频 / 影视传媒（886068 / 886060 / 886108）
1. 事实：AI视频 +5.74%、短剧游戏 +5.35% 领涨概念；中文在线、芒果超媒、海看股份、荣信文化 20cm 涨停；影视院线 +7.02%、出版 +5.26%、数字媒体 +7.19% 领涨行业。
2. 解读：大模型多模态能力迭代+短视频/微短剧需求爆发，AI 内容生产降本增效逻辑被市场重估；暑期档影视数据回暖叠加 IP 变现预期。
3. 映射：资金从资源/农业切向 AI 应用，AIGC 板块净流入 +64.63亿、人工智能 +129.07亿；游资主导连板与 20cm 弹性，机构减仓中军。
4. 操作：P3 高潮不追高，持仓者次日冲高兑现；若龙头（中文在线/芒果超媒）次日高开高走且资金继续流入，可视为 P3 延续，但需降低仓位。
P1AI智能体 / 算力硬件（886099 / 算力）
1. 事实：AI智能体 +1.91%、人工智能 +1.65%、东数西算 +2.29%；浪潮信息涨停但龙虎榜机构净卖。
2. 解读：AI 应用高潮后资金向底层算力与智能体扩散，但硬件端仍受 20 日资金线压制，部分龙头呈现“涨+净流出”诱多结构。
3. 映射：寒武纪涨停但板块资金 -9.53亿，说明个股行情与板块资金背离；补涨只能看低位硬件/光模块/服务器。
4. 操作：只做低位补涨，回避寒武纪等高位龙头；若算力板块净流入转正且持续 3 日，可升级为 P1。
退潮贵金属 / 有色 / 农业（885530 / 金属铅 / 885877）
1. 事实：黄金概念 -2.50%、主力资金净流出 -47.3亿；转基因 -2.13%、金属铅 -2.16%、大豆 -2.13%。
2. 解读：降息预期定价充分、金价高位回调，资金撤离资源股；农业连板股（万向德农/新赛股份）虽高标存活，但板块整体退潮。
3. 映射：防御与周期板块失血，资金切向 AI 成长主线。
4. 操作：规避，等待资金回流信号（板块止跌+主力净流入转正）。
