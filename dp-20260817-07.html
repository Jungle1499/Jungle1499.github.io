三阶段理论框架（一性原理 = 人性的扩张与收缩）

板块行情的完整周期分为三个阶段：犹豫期 → 共识期 → 加速期。

P1（启动）：逻辑龙头先涨；P2（二线）：后排补涨，涨速反超龙头 = 人性扩张；P3（高潮）：龙头涨速反超，群体狂热。

配对原则：选择市值可匹配、业务类似、涨幅最大的两个标的，例如光模块主升浪时 Pair = 中际旭创 / 新易盛，PCB 主升浪时 Pair = 胜宏股份 / 沪电股份。

起涨/阶段确认：板块进入全市场涨幅前三 = P1 预警；Pair 中的标的连续两天跑赢另一个 = 阶段确认（龙头连续 2 天跑赢补涨 = P1 确认；补涨连续 2 天跑赢龙头 = P2 确认；龙头再连续 2 天跑赢补涨 = P3 确认）。否则 P1 预警后，后排跑赢 1 天仅是 P2 预警，需重新计数。

买卖：P1 试错买入；P2 加仓补涨；上涨情绪周期可拿到 P3，退潮周期 P2 确认即陆续卖出。
