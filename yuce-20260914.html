框架

三阶段理论框架（第一性原理 → 阶段判定 → 配对 → 纪律）

第一性原理：人性的扩张与收缩
任何板块行情都不是"因为利好所以上涨"，而是参与者情绪从犹豫 → 共识 → 狂热 → 衰竭的扩张收缩循环。价格只是这个循环的读数。判断阶段比判断原因重要——同一条利好，在 P1 是买点，在 P3 是卖点。
P1 启动
少数龙头先动、板块指数刚翻红、市场普遍质疑、20日资金仍为负。
特征：涨停 1-2 只、广度 <60%、换手温和。
纪律：试错仓 ≤3%，只做龙头回踩。
P2 二线扩散
龙头确立后二线跟涨、子板块全线共振、成交额放大、涨停 3-6 只。
特征：广度 60-80%、多子板块同涨、机构开始现身龙虎榜。
纪律：顺势加仓，回踩 5 日线买。
P3 高潮 / 退潮
鸡犬升天、涨停潮、换手极高、遍地"机构上调目标价"。随后龙头先破位 → 二线补跌。
特征：涨停 ≥7 只或单日 ≥+5%、换手 >20%。
纪律：P2 确认即卖（三-③），一律不给"多"。
配对原则（三-②）与确认机制（三-④）
Pair 选取：市值匹配 + 业务类似 + 涨幅最大的两只。Pair 内部相对强弱是阶段判定的核心读数：
• 一方连续 2 天跑赢另一方 → 逐级确认 P1 → P2 → P3（禁止单日定阶段，日噪太大）
• 双方同步走强 → 板块 β 形成，主线成立
• 双方同步走弱 → 板块退潮，立即降档
• 权重龙头单列（三-⑧）：市值与板块其他成分差 >5 倍者不参与常规 Pair，另取可比二线构成判定 Pair
本日 Pair 实况：医药 Pair = 万邦医药(sz301520·59.26亿) vs 近岸蛋白(sh688137·53.70亿) → 市值高度匹配、同属 CRO/生物制品、双双 20cm 同步封板 → 同步走强 = β 成立，但需 T+1 再确认（连 2 天）方可升级 P2→P3。
买卖纪律速查（三-③）
P1 试错买P2 加仓P3 减仓退潮 P2 即卖权重锚单列 三-⑧连 2 天确认 三-④
