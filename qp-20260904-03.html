三阶段理论框架卡片（P1 启动 → P2 二线扩散 → P3 高潮 → 退潮）

第一性原理：人性的扩张与收缩
价格是表象，资金的「扩张→收缩」节奏才是本体。板块演进遵循 P1 启动（少数龙头试错）→ P2 二线扩散（补涨跟上、广度满红）→ P3 高潮（群体狂热、龙头占优）→ 退潮（补跌、无溢价） 的不可逆序列
阶段识别信号Pair 判定（三-② 市值≤5 倍 + 业务类似 + 涨幅最大两只）买卖纪律（三-③）
P1 启动板块进全市场涨幅前三 = 预警（三-①）；广度开始扩散但资金未连续Pair 内方向反复，未出现连 2 天跑赢试错买 ≤10% 仓
P2 二线扩散补涨跟上、广度近满红、5 日 + 20 日资金双正（㊹真趋势）Pair 内一方连 2 天跑赢 → 逐级确认 P2（三-①）加仓补涨（仅 P1 浮盈后）
P3 高潮群体狂热、龙头占优（Pair 内龙头连 3 天跑赢补涨）、加速放量Pair 内龙头连 3 天跑赢 = P3 特征；㊺ 退潮期 P3 加速段锁盈降级锁盈不加仓，破 5 日线减半
退潮首板无溢价、炸板率 >30%、20 日资金线深负（㊸禁多）板块指数转跌 + 资金连续流出P2 确认即卖，反弹=减仓窗口
约束规则：三-⑤逻辑龙头自动标定 = 板块内「5 日涨幅第一 + 主力净流入第一」，去主观； 三-⑥方向表 stage-aware 强制——多仅给 P1/P2 确认阶段，P3 / 退潮一律降为中性 / 减仓（禁止给多），并先判全局情绪面板，退潮期方向表整体降权（多 ≤2）； 三-⑦退潮日独苗主线豁免——唯一主线若已 P2 且 Pair 内补涨连 3 天跑赢 → 只给「中性偏多试错」不给「多·主攻」； 三-⑧权重龙头（市值与板块其他成分差 >5 倍）单独标定逻辑龙头，另取市值可匹配的二线构成 Pair，避免单一权重股扭曲板块阶段判定。
