三、【重点】机器人板块产业与投资总结（详细版）

以下为对话中说话人2主讲的产业链拆解 + 两人共识/分歧，比原始要点更完整。

1. 产业底层：模型路线从 VLA 切换到世界模型，数据需求性质改变

  • 去年：行业普遍用视觉模型（VLA 模型，端到端），国内大公司基本都是拿 VL/VA 模型去融资；彼时数据采集相对宽松，用"乌米"（？）或仿真数据去测就行。
  • 今年年初：发现 VLA 路线跑不通，集体转向世界模型。
  • 关键变化：世界模型要求真机数据（真集数据），仿真数据糊弄不过去。→ 这是本轮机器人炒作的产业起点，数据成为瓶颈环节。

2. OpenAI 入局：催化源头

  • OpenAI 约半年前判断世界模型"可能还可以"，开始用大模型做机器人能力提升，测下来结果不错，于是放话要做机器人（集成）业务。
  • 这是本轮的第一个催化事件。

3. A股映射链条①：利好"没有模型能力"的整机公司

  • 逻辑：OpenAI 模型训练效果被验证 → 国内缺"大脑"的整机公司可借 OpenAI 故事补位。
  • 举例：宇树（原话"语数"）原来只做本体、只有硬件能力，接上 OpenAI 的"大脑"故事就能成立；后续若模型真突破，它提前能买卖。
  • 本质：整机公司缺模型 → OpenAI 补位 → 估值故事成立。

4. A股映射链条②：真机采集三块 → 手部部件

真机数据分三块： 1. 数据的采集 2. 实际上手的动作 3. 大脑部分（思维/思灵类）

由此衍生手部部件线（说话人1理解并补充，标的名已确认）： - 斯菱智驱（转写"40"）：说话人1理解其为减速机方向，属"手"的部分，要用真机去练。 - 福来新材（转写"福来/扶来"）：做"手里面的部件"。 - 斯菱智驱（转写"自林/思琳"，与"40"为同一只票，对话中两处均指它）：也是减速机。 - 浙江荣泰（转写"融泰"）：做手里面的"小金杠"（小丝杠）。 - 结论：要练真机就得增加机器人的手（灵巧手/手部传动部件），→ 手部部件是第二条受益线。

5. A股映射链条③：数据服务商

  • 真机采完数据后，需数据服务商做标注与"阐述"，再交付给模型方（原话"给到那个歪歪的"，疑似指代某公司/平台，识别不明）。
  • 说话人2的实战教训：早上想到"为啥不炒数据"，嫌弱没买，晚上一看涨停了。→ 数据方向被其视为核心但难研究，主题炒作中位置关键。
  • 相关数据标的：说话人1系统昨日推出"海天瑞森"（疑似海天瑞声）、"创钉"（？）。

6. 感知环节：奥比中光 是真核心，机器视觉是资金外溢

  • 奥比中光：摄像头/感知，被说话人2认定为核心。
  • 奥普特、凌云光：属机器视觉，说话人2直接判为"纯扯淡"（不在真产业逻辑内）。
  • 为何会炒到机器视觉？ 资金/筹码解释，而非产业解释： 1. 炒到第二波时资金开始炒"数据要素"主题； 2. 数据要素板块里恰好包含机器视觉； 3. 那个板块筹码又干净 → 顺手炒上去。
  • 判断：不可持续，除非资金硬改。

7. 持续性判断与观察点

  • 看明天：马斯克（转写"马克"）讲话后，若明天出大阴线，能不能再拉起来——拉不回来即资金抱团结束。
  • 当前市场风格：简单粗暴，就炒 OpenAI 链；前两天炒 OpenAI 与特斯拉交叉的方向，现在"不喊车端了"。
  • 订单节奏：说话人2从客商处了解到11月会有新订单下来，但可能拖到11月中下旬。
  • 明年预期：说话人2认为今年/明年预期都不高；除非明年出B端产品，B端可能先做10万（台？数字识别不明）。对话中另出现"30""133""38"等产量数字，均识别不明，不作依据。

8. 大背景：AI 大应用"先软件、后硬件"，机器人是最大的硬件

  • 本质是在炒 AI 大应用：先炒软件，再炒硬件。
  • 机器人是最大的硬件，所以先炒一波。
  • OpenAI 自身也开始做硬件化（推出多款产品）→ 这两天端侧（端测）方向起来了。

9. 操作结论：共识与分歧

共识： - 极少人能把这条产业链递进逻辑讲清楚，绝大部分人在"瞎炒"；当前炒作偏技术面/资金面（"对线"），不是产业深度定价。 - 中线视角下，真正核心的是数据公司 + 感知公司（奥比中光）。

分歧 / 补充： - 说话人1：唯一正确的路是找中线公司（对北美有有效产能，如斯菱智驱和科森科技），等回撤时买入并拿着。 - 说话人2对"厂思维"（对北美产能逻辑）有保留，质疑"私下怎么可能干过绿的谐波"。 - 对照参照物：PCB（转写"3PB"）能干是因为有业绩；纯情绪的不能干。

10. 一句话总结

本轮机器人是"OpenAI 世界模型 + 真机数据"驱动的产业链递进炒作：真核心在数据公司与感知（奥比中光），手部部件与整机是第二层，机器视觉属资金/筹码外溢；市场理解深度普遍不足、偏资金抱团，持续性看次日能否拉回；稳健做法是找有真实产能的中线标的，等回撤买。
