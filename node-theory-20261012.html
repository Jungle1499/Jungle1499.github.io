概述：它到底解决什么问题

一句话：节点理论是一套建立在 westock data_market_overview 市场总评分序列上的「今天有没有资格出手」准入开关。

它不预测涨跌，只回答三个问题（交易三问）： ① 今天什么节点（能不能打）→ ② 打什么模式（M1~M6）→ ③ 赔率多少（值不值得下手）。
与 V4.1 的关系：平行互补，不是替代。
· V4.1 自下而上，回答「板块 / 个股在第几态（P1~P3九态）」，但对「今天该不该空仓」没有答案；
· 节点理论自上而下，回答「今天有没有资格出手」，补的是三级框架（大盘 gate + 行业 stage + 个股 alpha）里缺的顶层 risk gate。
它管什么、不管什么：节点只管买点（能不能买、买什么形态、给多少仓位）。它是一个买点框架——所以四种情绪位置里没有「高潮」档（那是该减仓 / 该卖的窗口，不在它的作用域）；它不处理卖点。
① 输入 westock 15 维→ ② ADJ 闸门 状态机→ ③ 题材源 三件套+聚类→ ④ 情绪×指数 查表→ ⑤ 输出 节点+仓位→ ⑥ 动作 M1~M6+赔率

①输入：一次调用拿到的 15 个维度 实锤

核心事实：不是"1 个主输入 + 11 个另取"。单次 data_market_overview(date=T-1, type=summary) 调用，一次返回 15 个 _SCORE + 15 个 _STATUS，全来自同一数据源。
状态机只吃 ADJ_SCORE 这一维跑判定；其余 14 维在原始报告里是旁证文字，没写进公式。

两层打分，必须说老实话：
· 第一层是 westock 黑箱——15 个分都是腾讯后端模型算好返回的，权重 / 公式 / 样本全未知。这是节点理论最大的脆弱点：westock 改算法或缺字段，整套判定全瞎。
· 第二层才是节点理论自己的判定——它只在 ADJ_SCORE 一维上做分档（Δ二阶导 + 滞回 ±5 + ≤11 冰点阈值）。
summary 包真给不了的 3 项（落地必须另取）：① 精确涨停 / 跌停家数 → data_changedist；② 最高连板高度 → 无直接工具，需自算；③ 是否破关键位 → data_index 取点位自比。

②心脏：ADJ 闸门状态机 实锤 5/5 复现

这套引擎的核心是一个带滞回（±5）的状态机。它看的是方向（二阶导）而不是水位高低——9/24 拿 19.86 判冰点、9/29 拿 18.96 判可攻，相差不到 1 分，结论完全相反。
Δ = ADJ_t − ADJ_(t-1) IF ADJ ≤ 11 → 冰点 / 退潮 # 深水区，不看方向，直接判 ELIF Δ ≤ −5 → 冰点 / 退潮 # 显著恶化，跌回冰点 ELIF Δ ≥ +5 且 题材成立 → 新核心题材节点（可攻） ELIF Δ ≥ +5 但 题材不成立 → 仅修复，不放行进攻 ELSE (−5 < Δ < +5) → 维持前一日判定 # 滞回区，防抖动

③题材从哪来：三件套过滤 + 动态聚类 实证 9/29 对账 4/4

定论：题材池 ＝ 概念排名快照 ＋ 三件套过滤 ＋ 动态聚类。
关键是分清：三件套是过滤器（守门员），不是题材的生产者。题材清单是"喂进来"的，不是状态机生成的。

⚠️ 最重要的边界：题材是同步描述器，不是前瞻触发器。
三件套告诉你的是「今天哪些板块成建制在涨」，不是「明天哪些会涨」。9/29 筛出的 4 个题材：9/30、10/8 连两日基本全死，仅 AI应用 在 T+3（10/9）才爆发 +3.46%；且题材隔日保留率极低（9/29→9/30 保留 0/4，10/8→10/9 保留 1/7），近乎一日游。按每日策略的评价窗口算，9/29 的题材策略在自身窗口是失败的，T+3 那次命中属于幸存者偏差。
→ 题材只用来"圈范围"，不用来做前瞻；择时交回 V4.1。

④情绪 × 指数错位：查表，不是算时间差 机制实锤 情绪源待补

机制：把「情绪状态」和「指数状态」两个离散状态并列查表，得到"等 / 抢 / 预备"的动作。
常说的"情绪领先指数 0.5~1 天"，是判定出"情绪已拐、指数没拐"之后的定性说法，不是先算出一个时间差数字再决策——"时间差大小"不是输入。
情绪状态指数状态判读动作
已前置触底（领先）仍在跌情绪领先，大资金提前拿先手预备性窗口 → 提前买最高身位
在杀在杀同步双杀，主跌中继不抢反弹
已释放完在跌双杀末端，易寻底等冰点确认再进
在上行横盘情绪跑在前面，方向未选预留预备仓，等 9:25 竞价

· 9/30 ＝ 指数弱跌 ＋ 接力情绪已触底 → 情绪领先 → 预备性窗口

⑤输出什么：3 个标签，2 个仓位桶 实锤

原始输出是 3 个节点类型标签，但落到仓位只有 2 个桶：
· 冰点 / 退潮 → 仓位 0-3%（单笔 ≤1.5-2%）
· 新核心题材节点（中） → 仓位 20-30%（单笔 ≤3%）
· 新核心题材节点（强） → 同属 20-30% 桶，「强」只是置信度更高、可取桶上限 30%，不是第三个仓位档。

中 / 强 判定中 ＝ Δ≥+5 且题材成立（单题材满足三件套）；强 ＝ Δ≥+5 且 ≥2 个题材同时成立（多题材共振）或板块广度显著抬升 推断（原始未落盘判定线）

「日历乘数」是什么：它不是 ×0.5 那种真乘法，而是节前 / 事件的降仓覆盖阀——遇到假期窗口，直接把基础仓位压到更低的上限：
· 节前最后交易日 → 仓位收敛至 10-15%　· 长假前 → 过节仓 ≤5%
所以「冰点 0-3% 遇长假 → ≤5%」「题材节点 20-30% 遇节前最后日 → 10-15%」。

⑥买点形态与赔率：M1~M6 + 死赔率

分工：节点解决"能不能下手"，M1~M6 解决"下什么手"。它们按个股身位分类（涨到几板、在梯队什么位置），本质是买点形态 / 动作分类框架——不负责筛选具体标的，具体买哪只由上游题材池喂入。
模式名称触发条件赔率
M12进3 加强确认主线高标封死，剩 2进3，高开带量即买点≈2-3
M2弱转强需高开 >3% 带量表态≈2-3
M3换手龙容量中军主线中军位置，需双确认≈2
M4补涨主线高位后，同题材低位首板≈2
M5双头 / 二波大题材缩量回调（换手<10%、地量企稳、不破10日线）→ 放量反包≈2-3（限大题材）
M65 天样本内未出现，暂无实例支撑
⚠️「赔率」到底是什么：是盈亏比，不是胜率。
赔率 ＝ 盈亏比（reward:risk），≈2 即约 2:1（赚 2 块、亏 1 块），≈2-3 即约 2:1~3:1。它不是概率、不是胜率——两者是独立维度：
· 盈亏比 2:1，打平只需胜率 ≈33%；3:1 只需 ≈25%。所以 2~3 的盈亏比意味着"经常亏、偶尔大赚"的高波动玩法，正是 M1 / M2 / M5 追板类动作的本来面目。
· 原始框架只给了盈亏比、没给胜率，所以"值不值得"其实缺一半（期望 ＝ 胜率×平均赚 − 败率×平均亏）。
· 「死赔率」的"死"＝ 写死的常量（今天 M1 是 ≈2-3，下个月还是），目的是同模式动作一致，不是每天重算。
和「严禁追高」铁律的关系（已闭环）：
M1 / M2 / M5 的触发（高开带量即买、高开>3% 表态、放量反包）本质是买强度、买启动，字面上撞「严禁追高」。解法不是删铁律，而是把禁忌精确重定义：
· 「严禁追高」＝ 禁止无框架逻辑支撑的追涨（见谁强追谁 / FOMO late-chase）；
· ≠ 禁止 V4.1 / 节点确认后的启动买点（首板、2进3、回踩不破的启动时介入）。
层级上：风控元层（止损 / 仓位 / 严禁追高）> 框架层（V4.1）。V4.1 的"最高"是指框架判据层内最高——它管「能不能买」，严禁追高管「怎么买」，资金安全高于框架信号，这本来就不冲突。
⚠️ 但这个豁免不能当免死金牌：「节点 / V4.1 确认的买不算追高」，安全性完全取决于判得准不准。判错的时候，"买 2进3"恰好就是普通追高（买在失败前的强）。所以豁免必须叠加三重约束：
① 必须经 V4.1 Pair 复核，与 V4.1 冲突一律按 V4.1 禁买　② 单笔 ≤3%　③ 影子运行 ≥10 交易日 + ≥20 样本后再正式采纳。

诚实边界：这套东西还没被证明"稳"

1. 样本太短，稳定性未证明：带交易三问 + M1~M6 的结构化版本，在 08:30 链路里只从 9/23 才插入，到 10/09 仅 7 个交易日，且全在 9/22 高点后的下杀腿里，从未见过 ADJ 40+ 的单边上扬市。按"跑得久才算稳"的标准，稳定性没有证明。
2. 阈值都是反推的，需要校准：ADJ≤11 冰点、滞回 ±5、三件套阈值、题材聚类锚词，全部是 7 个样本反推出来的，需 ≥20 交易日滚动校准才能算数。
3. 已经证伪、不能用的东西：① SENTIMENT（广度情绪）对相反判词零区分度，不能当错位判定的情绪输入；② ADJ 顶替情绪会导致判词矛盾，不能用；③ 题材是同步描述器，没有前瞻价值，只圈范围不择时。
4. 模式体系本身证据很薄：M6 无实例、M2 / M3 只在"条件预案"里出现过、没实盘启用过；赔率数字（≈2 / ≈2-3）原始报告直接给、没说怎么来的，而且只给盈亏比、没给胜率。
结论该怎么用：这套框架的价值在于提供"今天有没有资格出手"的顶层 risk gate——它补的是 V4.1 管不到的"该不该空仓"。但它目前只能当gate用，题材只圈范围、择时与确认交回 V4.1 Pair 相对强弱，在攒够 ≥20 样本、走完影子运行之前，不要把它当独立的选股依据。
