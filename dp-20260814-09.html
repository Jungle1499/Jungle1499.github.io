三阶段理论框架（一性原理 = 人性的扩张与收缩）

板块行情的完整周期分为三个阶段：犹豫期 → 共识期 → 加速期。

P1（启动）：逻辑龙头先涨；P2（二线）：后排补涨，涨速反超龙头 = 人性扩张；P3（高潮）：龙头涨速反超，群体狂热。

配对原则：选择市值可匹配（差 ≤ 5 倍）、业务类似（多维度交叉确认同类赛道）、涨幅最大的两个标的。例如光模块主升浪时 Pair = 中际旭创 / 新易盛，通信设备主升浪时 Pair = 亨通光电 / 中天科技。【框架应用 三-②】

起涨/阶段确认：板块进入全市场涨幅前三 = P1 预警；Pair 中的标的连续两天跑赢另一个 = 阶段确认（龙头连续 2 天跑赢补涨 = P1 确认；补涨连续 2 天跑赢龙头 = P2 确认；龙头再连续 2 天跑赢补涨 = P3 确认）。【框架应用 三-①】

买卖：P1 试错买入（≤10% 仓）；P2 加仓补涨（仅 P1 浮盈后）；退潮周期 P2 确认即陆续卖出。【框架应用 三-③】

上海印发《民间投资发展行动方案》，明确依法依规开展算力补贴，支持民营企业租用智算资源进行大模型研发训练。算力租赁概念全面爆发：数据港涨停、网宿科技 20cm 涨停、利通电子涨停。该政策直接催化 AIDC（数据中心）方向，5G 概念主力净流入 127.5 亿全概念第一，液冷服务器 +111.6 亿、CPO +111.1 亿紧随。
