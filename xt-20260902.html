▸ 📖 三阶段规则速查
Wave 结构：一个完整 W = P1 → P2 → P3；P3 确认 = 清仓离场 + 本 W 结束 → 等新信号 → 下一 W。
阶段触发条件操作
P1 预警Pair 中任一只当日涨幅 ≥7%（小幅上涨不算）试错仓位
P1 确认预警次日都上涨即确认；或触发当日追溯前一日已有 ≥7% 直接确认。龙头 = 预警日大涨者 A（B 累计涨幅更高则由 B 当）继续加试错仓位
P2 预警P1 确认后，补涨跑赢龙头 1 天继续加仓
P2 确认补涨累计强 2 天；或 P2 预警次日全跌（预警与确认同日）调仓加仓
P3 预警P2 确认后，龙头跑赢补涨 1 天准备降仓
P3 确认龙头累计强 2 天；或 P3 预警次日全跌（同日确认 + W 结束）清仓离场
中断① 任一只单日跌超 6%（次日龙头反包可恢复）② P1 确认后连续 2 日全跌 ③ P1 预警期双双下跌 / 龙头连跌 2 天清仓离场
W 结束P3 确认后龙头开始下跌 → 本 W 结束，等新 P1 启动下一 W清仓离场
情绪=退潮时规则收紧：P2 预警即减仓、P2 确认即减仓、P3 直接清仓。
▸ ⚔️ 操作纪律（心法层）
① 要信早信：主线在分歧阶段抢先手，超额收益 = 认知领先市场的收益。
② 躲开连接段 b：趋势中最猛的一段往往是陷阱，不追最猛的那一根。
③ 止损先行：买点出现但杀跌过猛 → 先止损，结构重建后再回补。
④ 空仓是交易的一部分：只做高胜率 + 高盈亏比窗口，等待不亏钱。
⑤ 退潮期轻仓保全本金：复利下回撤成本极高。
⑥ 一致预期往往意味着拐点；存量市场尤甚。
⑦ 心性大于技术：贪婪 / 恐惧 / 浮躁 / 执念是亏损的全部根源。
