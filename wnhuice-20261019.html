五、归因（为何命中 / 为何失准）

5.1 命中的三条共性

  1. 「可交易性分层」替代了「中长期逻辑硬映射」。本次源简报把 12 个方向按 T1/T2/T3/规避 排序，并对每个方向写明「是否可追」（低空「能否 2 板决定高度」、军工「题材脉冲不追高」、存储 / PCB / 光模块「反弹是减仓窗口」）。对比 10-12（30.8%）把「顶层文件 / 规划」直接映射周一方向，本次先判交易性、再判方向，命中率提升 19.2pp。这是本任务连续 5 次复盘里第一次把「方向」与「可交易性」拆开写。
  2. 看空侧全部建立在「海外映射 + 资金持续流出」双证据上。存储（费半 8 连跌、存储概念周跌 17%）、PCB / 光模块（Coherent / Ciena / 铠侠跌超 25%），且 A 股对应链 20 日主力净流出均在 -27 亿以上 → 三条看空 2 命中 1 中性，无反向。
  3. 机器人 / 军工的「低估」反而成了安全边际。源简报给机器人只判「中性偏多」（拓普 +4.93% 差 0.07pp 未触发）、军工判「题材脉冲不追高」，实际物理AI +7.14%、地面兵装 +5.22%。低预期 + 有真实资金流入的组合，是本次最大 α 来源。

5.2 失准的两条根因

  1. 油气：商品价格 → A股 传导第 4 次阻滞。布油 109.86（周 +4.9%，盘中触 110，5/19 以来首次）、WTI 周 +10.4%，但 A 股油价相关 -0.44%、油服工程 -0.06%、航运 -0.22%、炼化 +0.02%。根因：① 霍尔木兹 / 油轮触雷属地缘溢价，A 股资金视为「一次性事件」不给估值；② 航空 / 化工成本端利空与油气利好在同一账户内对冲；③ 源简报未跑规则61 路径 A 三条件（商品新高 ∧ 5D 转正 / 收窄 ∧ 广度 ≥60%），三条全不满足却仍给「偏多」。
  2. 碳纤维：D0 首日脉冲的必然衰减。10-16 双涨停（+9.45 / +13.62）本身是一日情绪脉冲，10-19 双跌（-1.11 / -1.92），资金同步流出（光威 -0.68 亿、中简 -0.09 亿）。源简报已写「否则按一日游处理」，但方向栏仍标「偏多」——条件式判断写进了备注、没写进方向栏，导致计分时被算作「看多」。

5.3 中性四条的解读

  • AI算力 / 国产芯片：政策强（国常会「人工智能+」、出口管制目录）vs 海外弱（费半周跌 11%）→ 内部对冲，算力芯片 +0.12%、半导体 -2.07%，方向不成立。
  • 金融 / 券商：金融街论坛 10/19 开幕 + 9 月数据 + LPR 预期，落地在银行（+1.55%，国有大行 +2.22%）而非券商（-0.09%）→ 政策预期被解读为「防御性红利」而非「风险偏好回升」，这是市场仍在防守的直接证据。
  • 光伏 / 锂电 / 汽车：反内卷政策属中期逻辑，光伏设备 +0.80%、汽零 +1.07%，但电池 -2.38% 拖累，方向被内部分化抹平。
  • 光模块 / CPO：CPO -0.01% 几乎走平，但新易盛主力 +8.32 亿（全市场第 2）、中际旭创 +2.50 亿 → 价平钱进，属超跌反抽的资金试探，方向未定。
