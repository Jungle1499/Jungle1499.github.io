一、计划遵守评分（满分 100 · 与五维交易质量评分并行）

维度分值判据
① 计划执行35当日条件已触发的计划项中，按计划执行的比例
② 冲动控制30计划外交易 0 笔=30 / 1 笔=18 / 2 笔=8 / ≥3 笔=0
③ 条件纪律20计划写了触发条件的，条件触发时是否照做（拍脑袋市价操作=0）
④ 计划质量15每条含标的+方向+触发价/条件+仓位=满分；「看情况/盘中定」类模糊项多=扣分

等级：≥85 优秀 / 70-84 良好 / 60-69 及格 / <60 需改进（同五维评分）。为什么并行两个分：五维评「交易做得好不好」，计划遵守评「有没有按自己说的做」——纪律性差的典型表现是计划写得好、盘中照样冲动（本周实例见下）。

二、计划台账（最新在前）

暂无计划记录。首条：周日 10-25 晚上把 10-26 周一的计划发给我（格式见下），我录入台账；周一收盘后比对实际成交打执行分。以后每晚一条，永久留存、倒序排列。

三、录入格式（照这个说就行）

【明日计划 2026-10-26 周一】 1. 骏亚科技：持有，跌破 17.5 清仓 2. 宇树科技：持有，涨停开板不回封减半 3. 新开仓：摩尔线程 回调低吸 ≤350，仓位 200 万 4. 禁做：医药、追高次新、计划外开仓

要点：标的 + 动作 + 触发价/条件 + 仓位，写得越具体，④计划质量分越高。 没写触发条件的「看情况」项 = 模糊项。录计划时我会对照纪律看板检查，若计划本身含追高/碰医药等 → 当场弹预警。

四、为什么要做交易计划（本周实例）

  • 10-21 追高 AI 芯片 855 万（燧原/沐曦/肯特当天套）—— 当晚如果有「不追高」的计划项，这笔大概率不会开。
  • 10-23 通则康威追高 -10.7% —— 纯盘中冲动单，计划里根本没有这只票。
  • 10-20 光智科技追高 —— 同上，计划外 + 追高双重违规。
  • 反例正面：10-23 低吸 AI 芯片买点满分（宇树涨停）—— 如果这是计划内的「回调低吸」，那就是教科书执行。

你的五维评分里买点经常拖后腿，根因不是不会买，是盘中临时起意。计划就是把「临时起意」挡在盘外的那道门。

交易计划 = 事前规则 + 事后执行比对。计划须你本人给出（AI 不代编）；执行评分只基于券商表真实成交。计划遵守分与五维质量分并行展示，周复盘汇总两者周趋势。
