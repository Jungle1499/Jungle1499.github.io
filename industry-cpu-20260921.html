  • 定价权回归：10 月初 PC CPU 拟再涨价约 10%（此前已涨一轮）
  • 基本面：Q2 营收 161 亿美元 +25% YoY；数据中心与 AI 63 亿美元 +59%；调整后毛利率 41.8%（去年同期 29.7%）；调整后 EPS 0.42（去年同期 −0.10）
  • 新增想象：Xeon 6 被选为英伟达 DGX Rubin NVL8 主机 CPU；SK 海力士或租用俄亥俄厂在美生产存储（未最终确定）；CEO 陈立武增持约 1000 万美元

1.3 传导链与⚠️关键区分

真受益（有订单/供货传导）：英特尔服务器 CPU 出货与单价上行 → ①服务器/AI PCB（广合科技、沪电股份、胜宏科技、深南电路）②IC 载板/封装基板（兴森科技、深南电路）③覆铜板 CCL（华正新材、生益科技）④封测（长电、华天、通富）⑤配套（澜起科技内存接口、鼎通科技连接器）。

⚠️非受益（仅主题情绪）：龙芯中科、海光信息、寒武纪、景嘉微、中国长城、禾盛新材——它们是国产自主路线，与英特尔 x86 是并行/竞争关系，英特尔卖得再好也不会给它们下单。禾盛新材尤其要注意：它持股熠知电子 17.05%，走的是 ARM 架构服务器 CPU（TF9000 对标英伟达 Grace），是 x86 的竞争者而非配套方。它们上涨只能靠「CPU 很火」的情绪扩散，不可按英特尔链逻辑定价。

四、结论 · 阶段总览与操作分组

P2 预警（最高档）服务器/AI PCB：广合科技 ↔ 兴森科技。9/21 广合涨停 +10% 反超 leader 兴森 → 人性扩张期。已非低位。
P1 预警（刚触发）封测：华天科技 ↔ 长电科技（D0=9/18）。
国产算力/信创：中国长城 ↔ 禾盛新材（D0=9/21）。均待 D2 确认。
P1 确认后整理PCB 龙头：深南电路 ↔ 沪电股份。未反超 → 未进 P2，稳健底仓档。
中断 / 未触发华正新材（9/17 −9.44% 中断）；海光、寒武纪、龙芯、景嘉微、澜起、鼎通、生益 未触发 ≥5%。

能关注（按三-③ 买卖纪律）

  • P1 试错仓 ≤10%：封测 Pair 的 华天科技（leader，D0 涨停）——但 D1 已回落至 +2.88%，建议等 9/22 D2 确认后再动，不抢在 9/22 高开时追
  • 回踩关注：兴森科技（42-43）、深南电路（382-385）— leader 回踩不破可持；沪电股份作同档底仓
  • 补涨候选：胜宏科技（9/21 +9.23%），但单日已亢奋，仅回踩参与

⚠️别追

  • 广合科技涨停价追高：已 +10% 封板，属 P2 主升中后段的追高，性价比差
  • 华正新材：9/17 −9.44% 已触发 v3.0 中断，CCL 环节走弱
  • 禾盛新材：ARM 路线与英特尔竞争，非受益；9/21 已 +5.28%，且 D0 刚触发未确认
  • 龙芯中科 / 海光信息 / 寒武纪 / 景嘉微：均未触发 ≥5%，主题沾边但资金未到
  • 中国长城：已触发但属信创主题，与英特尔无供货关系，9/22 未确认前不追

五、交易框架与风险

近端（9/22-9/23 靠什么）英特尔隔夜 +14.77% 情绪外溢；PCB 主线 P2 预警能否被「回溯前两日 2-of-3」确认；封测 D2=9/22 能否续涨
远端（10月后靠什么）10 月初 Intel PC CPU 涨价 10% 落地；18A / Panther Lake 放量；Terafab 与 SK 海力士合作落地；国产替代政策
风险清单（务必看）：
  • ① 9/22 高开兑现风险最大：A股 9/21 已抢跑（广合涨停、胜宏 +9.23%），隔夜英特尔大涨属「预期兑现」，高开后回落＝利好出尽的典型形态
  • ② P2 预警尚未 2-of-3 确认：若 9/22-9/23 不延续，服务器 PCB 主线会快速回落
  • ③ 覆铜板环节已中断（华正新材 −9.44%），上游材料走弱会反噬 PCB
  • ④ 国产 CPU/GPU 与英特尔无供货关系，仅情绪扩散，谨防「沾边即涨」后回落
  • ⑤ SK 海力士合作、Terafab 等均未最终确定，属想象空间非既成订单
  • ⑥ 英特尔自身仍亏损（TTM EPS 为负、Foundry 外部客户收入仅约 2.93 亿美元），转机叙事≠盈利已兑现
