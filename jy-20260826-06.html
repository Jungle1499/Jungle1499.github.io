比价配对框架 · 方法论总结

从「概念+产业逻辑配对」任务中抽离的纯方法骨架 —— 不含任何仓位/止损/不追高等投资纪律，可复用于任意「两标的相对强弱/补涨」场景。

配对构造 可比性过滤 量化指标 信号触发 池子维护

1配对构造：按「概念 + 产业逻辑」聚类

核心：把两只标的配成一对，依据的是它们在产业上的同源性，而不是价格走势的相似度。

为什么不用「走势最相似」

  • 同行业问句「和 X 走势最相似的股票」返回的是同日技术形态（如缩量、价跌量缩）的几百只杂股，跨行业混进茅台/招行，根本不可比。
  • 正确做法：同簇标的须处于同一产业环节或受同一概念驱动，天然可比、天然可对冲。

结构

  • 先按大方向分类（示例：电子计算机 / 通信传媒 / 电力设备 / 交运 / 医药），每方向下再拆簇（如「半导体设备」「液冷」「CXO」）。
  • 簇内成员需为真同环节标的，避免「沾边就塞」。

2可比性过滤：硬约束（可配置参数）

不是所有同簇标的都能配 —— 须满足可比性，否则比价信号失真。

市值可比
max(市值) / min(市值) ≤ 4×。逻辑：市值差太大 → 波动量级、资金属性、关注度不在同一量级，比价含义失真。龙头位放左，跟随位放右。
制度一致
涨跌幅制度须一致才算等价比较（示例：主板 10% 制 vs 双创 20% 制，同一 7% 阈值含义不等价）。不一致的 pair 降级处理，不参与高评级。
参数化提示：4× 与制度阈值都是可配置旋钮，换场景（如不同市场/不同资产）时按实际波动量级重设，不要当死规则。

3量化指标：不依赖 K 线，用行情快照即可

指标算法含义 / 用途
动量同步度 两只标的 [5日 / 10日 / 20日 / 60日 涨幅] 四维向量的余弦相似度 衡量中期是否同频。≥0.85 = 高同步；≥0.60 = 可用；<0.60 = 纯巧合，剔除。
20日离散度 龙头位20日涨幅 − 跟随位20日涨幅 正值 = 跟随位滞涨 = 补涨候选；负值 = 跟随位已领先。
市值比 max(市值) / min(市值) 第 2 节硬约束的实测值，同时用于评级（见第 4 节）。

4配对评级：A / B / C 三级

用于决定「监控优先级」与「是否值得推送」。

级条件定性
A市值比 ≤ 2 且 同步度 ≥ 0.85最优，互为镜像
B市值比 ≤ 3 且 同步度 ≥ 0.60可用
C仅满足硬性可比约束备选（制度不一致者归此）

5信号触发：阈值 + 共振 / 离散二分

一对中任一只达阈值即触发。阈值须做制度等价换算。

阈值等价
用「定价分位」而非绝对涨幅：示例主板 7% ≈ 涨停 70% 位；双创需 ~12% 才到同样分位。换算后两者才可比。
共振
双≥阈值 = 产业环节级共振（强信号）。
离散
单≥阈值、另一只滞涨 = 补涨机会，提示另一只可能接力（用第 3 节 20日离散度定位滞涨方）。

6信号研判门槛：只推「有机会的」

  • 机会门：动量同步度 ≥ 0.6 的同类 pair 才算「有机会」；<0.6 的纯巧合不推。
  • 盘中（实时）：只推 强共振 + 高同步补涨，过滤掉 C 级 / 弱共振 / 中等补涨，避免刷屏。
  • 盘后（统计/回测）：保留全量统计，但对「有机会」的标 ⭐ 标注，与盘中推送内容互补不重复。

7池子维护：增量模式（只加不减）

  • 并集原则：定期（如每日盘前）用新行情快照重算，与历史累计池取并集 —— 历史 pair 永不被删。
  • 休眠转正：市值比收窄重新满足约束的「休眠」pair 会自动转正，并标注原因。
  • 首现日：每对记录 first_seen（首次出现日），便于追溯。
  • 按日去重：推送侧同一 pair 当日只推一次，不因盘中先共振后分化而重复打扰。
  • 心跳：无新增时只发一句「池子稳定」状态，不重算/不重部署（省资源）。

8技术实现要点（可复用的工程经验）

数据源选型

  • 批量行情接口（示例 qt.gtimg.cn，50 只/批）含总市值 + 多周期涨幅，体积小、可脚本化，优于「问财 MCP 返回 90–110KB 自动落盘、且 503 频发」的通道。
  • 涨跌幅制度不能用行情字段直接取（字段错位陷阱），改用代码前缀判定（主板 / 创业板·科创 / 北交所）。

调度与门控分层

  • 定时任务用 DAILY + BYHOUR列表 + BYMINUTE列表（非 HOURLY，后者会退化成全局 tick 导致空跑）。
  • 脚本内再兜一层门控（工作日 / 未开盘 / 休市），双保险。

★端到端流程

① 簇定义→ ② 取市值/涨幅快照→ ③ 4× 可比过滤→ ④ 算同步度/离散度→ ⑤ A/B/C 评级→ ⑥ 阈值触发扫描→ ⑦ 机会研判(≥0.6)→ ⑧ 推送/归档
⑨ 盘后全量回测→ ⑩ 次日盘前增量(只加不减)↻ 回到 ②
本框架为方法论骨架，所有数值阈值（4× / 7%·12% / 0.85·0.60 等）均为示例参数，落地时按目标市场的实际波动量级重设。
