三阶段理论框架（一性原理 = 人性的扩张与收缩）

板块行情的完整周期分为三个阶段：犹豫期 → 共识期 → 加速期。

P1（启动）：逻辑龙头先涨；P2（二线）：后排补涨，涨速反超龙头 = 人性扩张；P3（高潮）：龙头涨速反超，群体狂热。

配对原则：选择市值可匹配、业务类似、涨幅最大的两个标的，例如光模块主升浪时 Pair = 中际旭创 / 新易盛，PCB 主升浪时 Pair = 胜宏股份 / 沪电股份。

起涨/阶段确认：板块进入全市场涨幅前三 = P1 预警；Pair 中的标的连续两天跑赢另一个 = 阶段确认（龙头连续 2 天跑赢补涨 = P1 确认；补涨连续 2 天跑赢龙头 = P2 确认；龙头再连续 2 天跑赢补涨 = P3 确认）。否则 P1 预警后，后排跑赢 1 天仅是 P2 预警，需重新计数。

买卖：P1 试错买入；P2 加仓补涨；上涨情绪周期可拿到 P3，退潮周期 P2 确认即陆续卖出。

催化剂 1
Lumentum FY26Q4 业绩全面超预期，AI 光互联需求验证
隔夜美股光通信龙头 Lumentum 公布截至 2026/6/27 的 FY2026Q4 财报：营收 10.1 亿美元（同比 +109%，超预期 2%），调整后 EPS $3.23（超预估 $2.97），调整后毛利率 50.4%（超预估 48.8%）。FY27Q1 指引营收 12.3-12.8 亿（指引中值 +8% vs 一致预期），EPS $4.05-4.35（+16% vs 一致预期），非 GAAP 经营利润率向 40% 迈进。CEO 表示超高功率 CPO 激光器需求爆发、ELS 模块获首批订单，光互联正从机架间向机架内渗透。
催化剂 2
源杰科技 42.68 亿元砸向光芯片产线，国产替代加速
光芯片龙头源杰科技 8/11 晚公告拟在陕西西咸新区投资 42.68 亿元建设源杰半导体科技产业园，含激光器芯片生产线 / 厂房等。项目直指 800G / 1.6T / CPO 上游核心卡脖子环节。源杰 H1 业绩预告净利润 6-6.5 亿（同比 +1196% 至 +1304%，半年净利下限已达去年全年 3 倍），毛利提升源自数据中心业务占比提升。该扩产直接打破"光芯片国产缺位"的稀缺叙事。
催化剂 3
炬光科技"中报+10 亿定增追光"，业绩与叙事双重共振
炬光科技今日开盘 20 分钟封死 20% 涨停（最大封单超 16 亿）。公司 H1 营收 4.19 亿元（+6.57%），光通信与消费电子业务爆发式增长；同步抛出不超过 10.21 亿定增，投向高端光互联核心光学元器件、高速光通信激光器衬底材料等产业化项目。中国银河证券研报指出，炬光科技、长光华芯、仕佳光子等业绩大幅超出市场预期。
催化剂 4
AI Capex 超级周期确认，2026 CSP Capex 突破 8867 亿美元
集邦咨询上修 2026 年全球九大 CSP 的 AI 服务器出货增速至 31%，资本开支合计将突破 8867 亿美元，2027 年进一步增至 1.32 万亿美元。叠加 Lumentum FY27Q1 指引高个位数的加速、上游 EML/CW 光芯片 / 磷化铟 (InP) 衬底产能存在较大缺口，AI 算力军备竞赛推动光互联成为核心瓶颈，国内光通信企业充分受益全球基建浪潮。
