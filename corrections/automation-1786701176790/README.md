# 每日修正 · 周末行业新闻搜集（周日 22:00 推送飞书）

本目录存放该任务**每日独立修正块**，base 模板（prompt.md）保持不动。

## 用法
每天你给的修正，写成独立文件：`automation-1786701176790/YYYY-MM-DD.md`

示例（automation-1786701176790/2026-09-20.md）：
```markdown
## 每日修正 2026-09-20
- 农业/种植 由 P1 升 P2（连板确认）
- 贵金属/有色 维持回避
- 次日仓位上限由 7 成调到 6 成
```

并入方式：将当日修正追加进 `automations/automation-1786701176790/prompt.md` 的 `## 每日修正` 段（sync_to_db 前），再 git commit。
